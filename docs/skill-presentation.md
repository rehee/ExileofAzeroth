## 1. 原则

技能**不逐个挑 WoW 法术**，而是按 DQQ 日志里技能的**标签和属性**组合出表现。一次技能表现分四层，每层独立决定：

| 层 | 内容 | 例：WoW 人类战士的顺劈斩 |
|----|------|--------------------------|
| ① 角色动作 | 施法者的身体动画 | 挥武器的动作 |
| ② 自身特效 | 施放时施法者身上或身边的特效 | 武器划过的光 |
| ③ 技能形状 | 技能作用范围的特效 | 绿色的弧形 |
| ④ 受击特效 | 被打中的单位：受击动画 + 命中特效 | 怪物的受击动作 |

DQQ 的技能也是同样的分层：`CastSkill` 日志带技能标签（`SkillTags`，已包含辅助宝石改动后的结果）、是否投射物（`IsProject`）、范围（`SkillArea`）、形状（`SkillShape`：中心、范围、形状）、阶段（`RenderPhase`：Launch/Impact），以及触发链（`TriggerSkill`、`TriggerFromSkill`）。

## 2. 角色动作（①）

### 2.1 判定顺序（高的优先）
| 优先级 | 条件 | 动作 |
|--------|------|------|
| 1 | **引导**（`Channel`） | 正常的引导施法动作（类似 WoW 的精神鞭笞、地狱烈焰）；**旋风斩例外**：旋转动作（见 2.3） |
| 2 | **主手是弓 + 攻击、没有肉搏**（`Attack`，无 `Melee`） | **射击动作**（拉弓射箭），带不带投射物标签都一样（用户 2026-11-07） |
| 3 | **投射物**（`Project`） | 定向施法动作（类似 WoW 施放火球：抬手朝目标一推）；**但近战技能受刀光剑影等辅助影响放出的投射物，用攻击动画**（挥砍） |
| 4 | **攻击 + 肉搏**（`Attack` + `Melee`） | 近战挥砍动作（按武器：单手、双手） |
| 5 | **法术**（`Spell`） | 施法动作 |
| 6 | 其他（战吼 `Warcry`、召唤 `Minion`、图腾 `Totem` 等） | 各自的动作（战吼：吼叫；召唤：施法） |

要点：
- **攻击分肉搏和非肉搏**：旋风斩是"攻击 + 肉搏"，但如果带了**投射物**标签，就不再按肉搏处理。
- **引导 + 投射物同时存在时，以引导为优先。**
- **弓**：主手是弓（`equipment.json` 里该物品 `"weapon": "bow"`），技能是攻击且没有肉搏标签时，一律用射击动作。普通攻击也是射击（"自动射击"，带飞行的箭）。引导仍然优先（暂定，遇到弓类引导技能再定）。

### 2.1.1 其余情况（用户 2026-11-07）
| 情况 | 动作 |
|------|------|
| 攻击、没有肉搏、不是弓也不是投射物（如幽灵凤凰箭） | **看手里的武器**：近战武器 → 近战攻击动作；远程武器 → 射击动作。幽灵凤凰箭限定弓或标枪；致伤毒药是辅助，不能单独使用（用户 2026-11-07） |
| 光环（`Aura`：正义之火、神圣之火、神圣冲击、神圣冻结） | **不做动作**；开启时播放类似 WoW 圣印的效果（按元素着色） |
| 冲锋、野蛮冲撞 | WoW 战士冲锋：向前冲，带一道拖影 |
| 闪空脚（`Shoryu`） | 踢腿或上勾拳的动作 |
| 霜之新星（`Nova`，没有法术标签） | 同烈焰新星、新星爆发：施法动作，加一圈向外扩散的特效 |
| 尸爆 | 施放者做施法动作（类似 WoW 施放审判的动作），尸体位置爆炸 |
| 自毁命令 | 施放者做施法动作（类似施放审判） |
| 战吼（`Warcry`） | 进入战斗立刻释放一次（之后靠持续效果在身上，不再释放）。DQQ 不为它写施放日志，只给施放者及友方加上持续效果 `BattleShout`：**以持续效果出现为施放时刻**，播放吼叫动作和战吼特效 |
| 超级霸王电影弹 | 读条，然后向目标地点位移，对路上的敌人造成伤害（用户 2026-11-07）。DQQ 只写伤害日志：读条开始以技能进入冷却为准（角色快照里的技能冷却），位移本身由坐标表现 |
| 怪物专用技能（撕咬、巨力重击……，没有标签） | 用**怪物自己的攻击动画**作为这个技能的动作演出（怪物模型的动画很少），特效照常按元素与形状 |

### 2.2 引导的连续性
引导是持续动作。每一帧看施法者是否仍在引导：
- 还在引导 → 继续当前引导动作，**不重新开始**；
- 不在引导 → 先不停；**连续几帧都不在引导**才停止，回到战斗待机。

这样不会出现"引导 1 帧、停 1 帧、再引导"的抽搐。客户端不缓冲、不往后看（用户 2026-11-07 确认），代价是引导真正结束后动作会多播那几帧才停。

### 2.3 例外：旋风斩
旋风斩（`Whirlwind`）是引导，但动作是**人物旋转**（WoW 战士旋风斩的旋转动画），不是普通的引导施法动作。旋转是①角色动作；人物身边的刀光是②自身特效。

## 3. 自身特效（②）与技能形状（③）

- **自身特效**：施放时（Launch）在施法者身上或武器上播放，按元素着色或选型（物理：刀光；火焰：火焰；冰霜：冰；闪电：电弧；混沌：暗影）。
- **技能形状**：按 `SkillShape` 与范围、中心：

| 形状 | 表现 |
|------|------|
| Cleave（顺劈） | 施法者前方的弧形 |
| All（全体 / 新星） | 以中心为圆心的新星，半径 = 范围 |
| Chain（连锁） | 在目标之间跳跃的链 |
| Ray（射线） | 从施法者到目标方向的光束 |
| Scatter（散射） | 多个方向的散射 |
| Random | 随机位置的落点 |

形状的颜色或样式由元素决定。

## 4. 受击特效（④）

被技能打中的单位（`DamageTaken`）：
- 受击动画（WoW 的受伤动作，暴击时用重伤动作）；
- 命中特效，按元素选；
- 伤害飘字，按元素着色。

## 5. 投射物

- 投射物是一个**飞行物体**，按元素等属性选各种球体的样子（火球、冰球、电球、暗影球……）。
- **近战技能受刀光剑影等辅助影响而放出的投射物**（技能有攻击 + 肉搏，辅助加上了投射物），用剑气、刀光一类的投射物（WoW 里有合适的就用），而不是元素球。
- 飞行路线跟随 DQQ 的投射物位置（`projects[]`）。
- 投射物**破碎（命中或到达）后会施放对应的技能**：这个技能的②③④表现与人物亲自施放时**完全一样**，只是没有①角色动作，并且以破碎位置为中心。

## 6. 例子：旋风斩 + 暴击时施放 + 刀光剑影 + 旋风斩

| 时刻 | DQQ 日志 | 表现 |
|------|----------|------|
| 玩家施放第一个旋风斩 | 标签含 引导 + 投射物（辅助带来的投射物） | 引导优先 → 人物旋转（①），身边刀光（②），范围伤害（③），被打中的怪物受击（④）；只要还在引导就一直转 |
| 暴击触发 | `CastOnCriticalStrike` 触发第二个旋风斩，带投射物 | 第二个旋风斩是**投射物**：飞出一个球体 |
| 投射物破碎 | 投射物施放旋风斩 | 在破碎位置播放和人物施放旋风斩**一样**的特效（刀光、范围、受击），但没有人物旋转 |

## 7. 资源选用

- 动作用 WoW 的动画编号（`AnimationData.dbc`：近战攻击、施法、引导、投掷、射击、旋转等）。
- 特效借用 WoW 法术的视觉（`SpellVisual` / `SpellVisualKit`）：桥接发 `SpellStart` / `SpellGo` 或直接播放视觉组件，客户端已实现整套视觉链（PLAN-0004）。
- 具体编号写进对应表（PLAN-0006）：按"动作类型""元素 × 层"建表，而不是按技能建表；个别技能需要时再单独覆盖（例如旋风斩的旋转）。
