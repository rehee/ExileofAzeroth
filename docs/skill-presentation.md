## 1. 原则

技能**不逐个挑 WoW 法术**，而是按 DQQ 日志里技能的**标签和属性**组合出表现。一次技能表现分四层，每层独立决定：

| 层 | 内容 | 例：WoW 人类战士的顺劈斩 |
|----|------|--------------------------|
| ① 角色动作 | 施法者的身体动画 | 挥武器的动作 |
| ② 自身特效 | 施放时施法者身上或身边的特效 | 武器划过的光 |
| ③ 技能形状 | 技能作用范围的特效 | 绿色的弧形 |
| ④ 受击特效 | 被打中的单位：受击动画 + 命中特效 | 怪物的受击动作 |

DQQ 的技能也是同样的分层：`CastSkill` 日志带技能标签（`SkillTags`，已包含辅助宝石改动后的结果）、是否投射物（`IsProject`）、范围（`SkillArea`）、形状（`SkillShape`：中心、范围、形状）、阶段（`RenderPhase`：Launch/Impact），以及触发链（`TriggerSkill`、`TriggerFromSkill`）。

## 2. 角色动作（①）

### 2.1 判定顺序（高的优先）
| 优先级 | 条件 | 动作 |
|--------|------|------|
| 1 | **引导**（`Channel`） | 正常的引导施法动作（类似 WoW 的精神鞭笞、地狱烈焰）；**旋风斩例外**：旋转动作（见 2.3） |
| 2 | **主手是弓 + 攻击、没有肉搏**（`Attack`，无 `Melee`） | **射击动作**（拉弓射箭），带不带投射物标签都一样（用户 2026-11-07） |
| 3 | **投射物**（`Project`） | 定向施法动作（类似 WoW 施放火球：抬手朝目标一推）；**但近战技能受刀光剑影等辅助影响放出的投射物，用攻击动画**（挥砍） |
| 4 | **攻击 + 肉搏**（`Attack` + `Melee`） | 近战挥砍动作（按武器：单手、双手） |
| 5 | **法术**（`Spell`） | 施法动作 |
| 6 | 其他（战吼 `Warcry`、召唤 `Minion`、图腾 `Totem` 等） | 各自的动作（战吼：吼叫；召唤：施法） |

要点：
- **攻击分肉搏和非肉搏**：旋风斩是"攻击 + 肉搏"，但如果带了**投射物**标签，就不再按肉搏处理。
- **引导 + 投射物同时存在时，以引导为优先。**
- **普通攻击动作与特殊攻击动作**（用户 2026-11-12）：WoW 原版有自动攻击（Attack1H/2H，移动时只播上半身，边跑边砍）与特殊攻击（英勇打击、猛击的 Special1H/2H，强制全身）两套动作，DQQ 没有这个区分，按技能标签定：带**基础**（`Basic`）或**核心**（`Core`）标签的挥砍用普通攻击动作；其他的（大师、终极、战术……）用特殊攻击动作（`skills.json` 的 `actions.special` 英勇打击 78、`special2H` 猛击 1464，空手时客户端换成 SpecialUnarmed）。只对英雄；怪物用自己的攻击动画。技能形状带来的特效（顺劈的刀光）不再带自己的动作，见 `docs/mapping-config.md` 的锥形。
- **弓**：主手是弓（`equipment.json` 里该物品 `"weapon": "bow"`），技能是攻击且没有肉搏标签时，一律用射击动作。普通攻击也是射击（"自动射击"，带飞行的箭）。引导仍然优先（暂定，遇到弓类引导技能再定）。

**旋转**（`Spin` 标签，用户 2026-11-10，DQQ 新加）：英雄或怪物施放带 Spin 的技能就转一圈（借旋风斩 1680：旋转动作——模型有的话——加脚下的旋风特效和呼呼声）；Spin + 引导一直转（借引导版旋风斩 28334，按 §2.2 的引导判断延长、约 0.8 秒没日志就停，旋风和呼呼声随引导循环）。旋转比移动优先（用户 2026-11-10）：转着的单位边转边往前走，不换成跑步动作（客户端 Exile 改动：引导动作是旋转 126 时，动画按站着算，位置照样移动）。声音在法术特效包里，和旋风特效一起放在施放者身上，所以跟着角色和旋风一起走。投射物爆炸处的旋风见下条。

**旋转技能的投射物**（幻影之刃辅助等，用户 2026-11-10）：投射物照常飞（按元素的飞行法术）；碰到敌人时 DQQ 记一条出自投射物的区域日志，由这个投射物（客户端里沿 DQQ 路径移动的投射物单位）施放旋风斩（1680，事件动作 `projectileSpin`），先落到地面再施放（投射物单位飞在身体高度，旋风要贴地），在那里播旋风和呼呼声。碰撞那一帧投射物往往刚消失：它的单位还会停留约 0.8 秒等弹道落地，这段时间里仍由它施放；更晚才在那个位置另放。英雄自己转的旋风斩已有旋转动作，它的区域日志不另播。

**主手魔杖**（用户 2026-11-10）：战斗站姿按匕首（拿着魔杖站匕首的准备姿势）；带肉搏、不带投射物标签的攻击用匕首的攻击动作；其他攻击用魔杖的射击（法术 5019，`skills.json` actions.wandShoot），射完约 1.2 秒回到匕首站姿。

**拿弓时的攻击**（用户 2026-11-09）：主手是弓、技能是攻击时都是射击动作；只有带肉搏（Melee）标签且不带投射物（Project）标签的攻击，拿着弓用双手武器挥砍。

### 2.1.1 其余情况（用户 2026-11-07）
| 情况 | 动作 |
|------|------|
| 攻击、没有肉搏、不是弓也不是投射物（如幽灵凤凰箭） | **看手里的武器**：近战武器 → 近战攻击动作；远程武器 → 射击动作。幽灵凤凰箭限定弓或标枪；致伤毒药是辅助，不能单独使用（用户 2026-11-07） |
| 光环（`Aura`：正义之火、神圣之火、神圣冲击、神圣冻结） | **不做动作**；开启时播放类似 WoW 圣印的效果（按元素着色） |
| 冲锋、野蛮冲撞 | WoW 战士冲锋：向前冲，带一道拖影 |
| 闪空脚（`Shoryu`） | 踢腿或上勾拳的动作 |
| 霜之新星（`Nova`，没有法术标签） | 同烈焰新星、新星爆发：施法动作，加一圈向外扩散的特效 |
| 尸爆 | 施放者做施法动作（类似 WoW 施放审判的动作），尸体位置爆炸 |
| 自毁命令 | 施放者做施法动作（类似施放审判） |
| 战吼（`Warcry`） | 进入战斗立刻释放一次（之后靠持续效果在身上，不再释放）。DQQ 不为它写施放日志，只给施放者及友方加上持续效果 `BattleShout`：**以持续效果出现为施放时刻**，播放吼叫动作和战吼特效 |
| 超级霸王电影弹 | 读条（蓄力），然后向目标地点位移，对路上的敌人造成伤害（用户 2026-11-07）。DQQ 不写施放日志，按三样事实判断（用户 2026-11-07）：**读条开始** = 施放者身上出现无敌（`DamageInvincibility`，蓄力时加，3 秒）→ 施法（蓄力）动作；**释放** = 出现 `ChoukyuuHaouDenEidan` 持续效果（0.3 秒）且角色在移动 → 冲刺动作与拖影；伤害日志 → 路上敌人的受击特效 |
| 怪物专用技能（撕咬、巨力重击……，没有标签） | 用**怪物自己的攻击动画**作为这个技能的动作演出（怪物模型的动画很少），特效照常按元素与形状 |

**没有施放日志的技能**：用角色快照里的事实补出施放时刻——持续效果出现（runtime 比较前后帧的 `Durations`，生成"持续效果开始"事件）、`CastSkill` 日志、角色是否在移动。对应表可以按持续效果配表现（例如 `BattleShout` 出现 → 战吼；`ChoukyuuHaouDenEidan` 出现 → 冲刺）。

### 2.1.3 攻击动作的特殊规则（用户 2026-11-12）
WoW 原版有自动攻击（普通攻击动作）与特殊攻击（英勇打击、猛击、盾击……）两套动作，DQQ 没有这个区分。规则（只对英雄；怪物用自己的攻击动画）：

| 情况 | 动作 | 做法 |
|------|------|------|
| 挥砍，技能带**基础**（`Basic`）或**核心**（`Core`）标签 | 普通攻击动作（单手 Attack1H、双手 Attack2H/2HL、匕首 Attack1HPierce、空手 AttackUnarmed，按主手武器） | 原版自动攻击包；移动时只播上半身，边跑边砍 |
| 挥砍，其他标签（大师、终极、战术……） | 特殊攻击动作（Special1H；双手武器、弓 Special2H；空手时客户端换成 SpecialUnarmed） | 伤害到达时施放英勇打击 78 / 猛击 1464（`skills.json` `actions.special`/`special2H`），命中处打击闪光；原版强制全身播放 |
| **盾击**（`ShieldBash`） | 盾牌猛击动作（ShieldBash，59） | 伤害到达时施放盾击 72（`skills.special` 覆盖），命中处打击特效 |
| **迅猛攻击**（`SwingAttack`）：主副手同时攻击 | 主手挥砍，紧接着副手挥砍 | 1.12 没有双手同时砍的单个动作，两个挥砍同一瞬间播放只剩后一个，所以主手先砍、0.2 秒后副手再砍；伤害数字分成两半各显示一次。副手空着（或拿盾）时副手是空手挥击 |
| **双持**（副手拿着武器）的普通挥砍 | 左右手轮流：一下主手、一下副手（副手：匕首 AttackOffPierce，其他武器 AttackOff） | 原版自动攻击包的 HITINFO_LEFTSWING；runtime 按出手轮流标副手，同一次出手打中的几个目标用同一只手 |

| **超级霸王电影弹**（用户 2026-11-12 的特殊规则） | ① 近战蓄势 → ② 冲刺（周身被火焰气团笼罩）→ ③ 特殊攻击（不吼叫） | DQQ 不写蓄力的日志，只在蓄力时给英雄加 3 秒的无敌：它出现时英雄读条猛击 1464（只借读条的预备动作 ReadyAbility 近战蓄势；蹲下 SpellKneelLoop 和模型不搭，用户 2026-11-12 改掉，时长取技能定义的 `CastTime`，超级霸王电影弹 1.5 秒；DQQ 没有读条日志，回放里不显示施法条，用户 2026-11-12），冲刺开始时打断；冲刺与攻击按下面两行。`skills.json` 的 `chargeUps`（七星闪的无敌总时长 0，不算） |
| **冲刺**（冲锋、野蛮冲撞、七星闪、超级霸王电影弹……） | 跑动加冲锋音效、拖尾 | DQQ 的冲锋类是快速位移（每帧 0.13～0.6 单位，普通移动约 0.02），施放日志要等撞到目标才来；runtime 按英雄每帧位移超过 `dash.speed` 认作冲刺：开始时施放冲锋 100（冲锋声、胸口拖尾、落地扬尘，只播施法），冲刺期间挂速度 23451（身后拖尾） |

**buff 不配动作**（用户 2026-11-12）：持续效果（无敌等）是 buff，只按 `auras` 在身上挂特效（无敌：圣盾术的护罩），不做施放动作。技能的动作只由技能规则定。

技能形状带来的特效（顺劈的刀光）不带自己的动作（见 `docs/mapping-config.md` 的锥形），动作只由这张表定。

### 2.1.2 引导的姿势（用户 2026-11-07）
射线类引导（瓦解射线、冰霜射线、奥术洪流……）一律用**向前指的引导姿势**（WoW 的 ChannelCastDirected，像吸取生命、精神鞭笞），不用举手的全向引导。实现：施放者进入 WoW 的引导状态（`UNIT_CHANNEL_SPELL`），借用的引导法术都是向前指的（`skills.json` actions.channel），并且选声音全程循环的（精神鞭笞、吸取法力、吸取生命；用户 2026-11-08）。

### 2.2 引导的连续性
引导是持续动作。每一帧看施法者是否仍在引导：
- 还在引导 → 继续当前引导动作，**不重新开始**；
- 不在引导 → 先不停；**连续几帧都不在引导**才停止，回到战斗待机。

这样不会出现"引导 1 帧、停 1 帧、再引导"的抽搐。实现：该技能的每个施放、伤害日志都把引导延长到 0.8 秒后，过了 0.8 秒没有新日志才停。客户端不缓冲、不往后看（用户 2026-11-07 确认），代价是引导真正结束后动作会多播那几帧才停。

### 2.3 例外：旋风斩
旋风斩（`Whirlwind`）是引导，但动作是**人物旋转**（WoW 战士旋风斩的旋转动画），不是普通的引导施法动作。旋转是①角色动作；人物身边的刀光是②自身特效。

## 3. 自身特效（②）与技能形状（③）

- **自身特效**：施放时（Launch）在施法者身上或武器上播放，按元素着色或选型（物理：刀光；火焰：火焰；冰霜：冰；闪电：电弧；混沌：暗影）。
- **技能形状**：按 `SkillShape` 与范围、中心：

| 形状 | 表现 |
|------|------|
| Cleave（顺劈） | 施法者前方的弧形 |
| All（全体 / 新星） | 以中心为圆心的新星，半径 = 范围 |
| Chain（连锁） | 在目标之间跳跃的链 |
| Ray（射线） | 从施法者到目标方向的光束 |
| Scatter（散射） | 多个方向的散射 |
| Random | 随机位置的落点 |

形状的颜色或样式由元素决定。

**区域按日志渲染（用户 2026-11-07）**：技能生效时 DQQ 写技能区域日志（`SkillRangeAndTarget`：形状、半径、中心），表现以它为准——例如火球命中处的爆炸按日志里的中心和半径播放（对应表 `skills.json` 的 `areas`）。

**圆形区域按技能标签选动画（用户 2026-11-07）**：冲击波、冰霜新星一类向外扩散的动画，按技能标签（元素、近战等）选。

**散射画成射线（用户 2026-11-07）**：形状日志的类型是散射时，从出发点向结束的位置发射射线，射线的形态和颜色按技能标签决定。例：火球 + 散射——火球爆炸后，从爆炸中心发出火焰射线灼伤敌人。

**烈焰新星是特例（用户 2026-11-07）**：它向四周发射火球（DQQ 投射物），自身的爆炸没有伤害，不渲染新星圈；只做施法动作，火球按投射物画。

### 3.x 持续效果的常驻特效与范围圈（2026-11-11）
持续效果（DQQ 的 Duration）在单位身上期间，客户端把借用的 WoW 光环写进它的光环栏，光环的“状态”特效（护盾罩、着火、脚下结冰……）就一直挂着，效果没了就消失；回到自由模式时本体身上的清掉。对应关系在 `skills.json` 的 `auras`（Claude 先挑，用户审）。

**范围圈**（用户 2026-11-11：正义之火像 PoE 那样显示范围）：效果的主人周围沿判定距离放一圈挂着光环的隐形单位（正义之火：14 个着火点，半径 = DQQ 的 `EnumDistance.Middle`，runtime 运行时向 DQQ 取），跟着主人移动。用户看过后不要火柱，改成地面上的圆（2026-11-11）：借用地面法术的区域模型（正义之火用奉献的金色法阵），客户端把它放在主人脚下、按范围缩放（`ring.area` + `native`，Exile 改动：原版只给地面法术画、不缩放）。一圈点的画法（`ring.spell` + `count`）保留备用。

**开启光环的动作**（用户 2026-11-11）：同一个单位的同一个光环只在第一次激活时做一次举手的施法动作（`actions.aura`，借心灵之火、冰甲术等），之后被动激活不做任何动作。

## 4. 受击特效（④）

被技能打中的单位（`DamageTaken`）：
- 受击动画（WoW 的受伤动作，暴击时用重伤动作）；
- 命中特效，按元素选；
- 伤害飘字，按元素着色；
- 受伤叫声（用户 2026-11-08）：法术伤害没有挥击，客户端按肉搏命中的规则给受击者播受伤叫声（暴击必播），持续伤害的跳数不播；
- 死亡：DQQ 一杀死敌人就把它从帧里去掉，客户端先把它的生命设为 0（播死亡动作和死亡叫声），尸体留 3 秒再移除；`Killed` / `ActorIsDown` 日志也把生命设为 0。

伤害飘字只在日志里的法术会记录（`Spell.dbc` 没有 `DO_NOT_LOG`）时显示。借用的引导法术都不记录，有的技能也没有法术，所以伤害日志一律按伤害类型另选会记录的法术：物理 射击 75、火焰 火球 133、自然（闪电）闪电箭 403、冰霜 寒冰箭 116、暗影（混沌）暗影箭 686、奥术 奥术飞弹 7268；治疗没有法术时用次级治疗术 2050。

## 5. 投射物

- 投射物是一个**飞行物体**，按元素等属性选各种球体的样子（火球、冰球、电球、暗影球……）。
- **近战技能受刀光剑影等辅助影响而放出的投射物**（技能有攻击 + 肉搏，辅助加上了投射物），用剑气、刀光一类的投射物（WoW 里有合适的就用），而不是元素球。
- 飞行路线跟随 DQQ 的投射物位置（`projects[]`）。
- 投射物**破碎（命中或到达）后会施放对应的技能**：这个技能的②③④表现与人物亲自施放时**完全一样**，只是没有①角色动作，并且以破碎位置为中心。

## 6. 例子：旋风斩 + 暴击时施放 + 刀光剑影 + 旋风斩

| 时刻 | DQQ 日志 | 表现 |
|------|----------|------|
| 玩家施放第一个旋风斩 | 标签含 引导 + 投射物（辅助带来的投射物） | 引导优先 → 人物旋转（①），身边刀光（②），范围伤害（③），被打中的怪物受击（④）；只要还在引导就一直转 |
| 暴击触发 | `CastOnCriticalStrike` 触发第二个旋风斩，带投射物 | 第二个旋风斩是**投射物**：飞出一个球体 |
| 投射物破碎 | 投射物施放旋风斩 | 在破碎位置播放和人物施放旋风斩**一样**的特效（刀光、范围、受击），但没有人物旋转 |

## 7. 资源选用

- 动作用 WoW 的动画编号（`AnimationData.dbc`：近战攻击、施法、引导、投掷、射击、旋转等）。
- 特效借用 WoW 法术的视觉（`SpellVisual` / `SpellVisualKit`）：桥接发 `SpellStart` / `SpellGo` 或直接播放视觉组件，客户端已实现整套视觉链（PLAN-0004）。
- 具体编号写进对应表（PLAN-0006）：按"动作类型""元素 × 层"建表，而不是按技能建表；个别技能需要时再单独覆盖（例如旋风斩的旋转）。
