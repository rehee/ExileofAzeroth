## 目标
做出 Windows 启动器，玩家放到 WoW 目录运行即可获得最新版本并开始游戏。

## 范围
- 包含：启动器、发布清单、GitHub Releases 流程、打包、合规声明。
- 不包含：游戏内容。

## 任务清单
- [ ] 打包：客户端（benilla 分支）、runtime（含 `source/dqq/`）、插件、中文字体
- [ ] 发布清单：版本号、文件、哈希；GitHub Releases 自动发布（CI）
- [ ] 启动器（C#、Avalonia）：校验 WoW 1.12.1 enUS、检查更新、下载、校验、备份与回滚、安装
- [ ] 启动顺序：先启动 runtime，就绪后启动客户端；客户端退出时 runtime 退出（D26）
- [ ] 发布版的客户端状态与插件目录（开发版在 `benilla-config/`，发布版在客户端旁）
- [ ] 启动器自更新
- [ ] 合规：不分发暴雪资源、非官方声明、benilla 许可声明

## 验收标准
- 在一台只装了 WoW 1.12.1 的电脑上，下载启动器、运行，即可自动安装并进入游戏；有新版本时自动更新。
