# 工作流程：计划与进度

## 新建计划
1. 查看 `plans/PROGRESS.md`，取下一个可用编号。
2. 复制 `agents/templates/plan-template.md` 为 `plans/PLAN-XXXX-简短名称.md`。
3. 填写目标、范围、任务清单、关联设计文档。
4. 在 `plans/PROGRESS.md` 的计划总表中新增一行。

## 执行计划
1. 认领：填写负责人，状态改为 `进行中`（计划文件 + PROGRESS.md 同步修改）。
2. 按任务清单推进，完成一项勾选一项。
3. 每次会话结束前追加一条「进度日志」，并更新 PROGRESS.md 的完成度与最后更新日期。

## 完成 / 中断
- 完成：状态改为 `已完成`，写明验收结果与产出位置。
- 中断：状态改为 `暂停` 或 `阻塞`，在「讨论/交接」区写清原因与接手所需信息，负责人可清空以便他人认领。

## 状态取值
| 状态 | 含义 |
|------|------|
| `待开始` | 已创建，无人认领 |
| `进行中` | 已认领，正在执行 |
| `阻塞`   | 依赖未满足或遇到问题，需要处理 |
| `暂停`   | 主动搁置 |
| `已完成` | 全部任务完成并验收 |
| `已取消` | 不再执行（保留文件，不删除） |

## 设计文档
- 新建时复制 `agents/templates/design-template.md` 到 `docs/`。
- 在 `docs/README.md` 的索引中登记。
