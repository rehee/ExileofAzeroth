# agents/ — AI 协作入口

本项目是 **多 AI 共同参与的公共项目**。任何 AI（Claude、GPT、Gemini、Copilot 等）开始工作前，必须先阅读本目录。

## 阅读顺序
1. [RULES.md](RULES.md) — 通用规则与约束（必读）
2. [WORKFLOW.md](WORKFLOW.md) — 计划与进度的工作流程（必读）
3. [templates/](templates/) — 计划、设计文档模板
4. `agents/<ai-name>.md`（可选）— 某个 AI 专属的补充说明

## 目录约定
| 目录 | 用途 |
|------|------|
| `agents/` | 所有 AI 相关文件：规则、约束、工作流、模板、各 AI 专属说明 |
| `docs/`   | 所有设计文档 |
| `plans/`  | 项目进度：每个计划一个文件 + 总进度文件 `plans/PROGRESS.md` |
